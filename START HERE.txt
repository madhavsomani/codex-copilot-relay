CODEX COPILOT RELAY - QUICK START

This folder contains the self-contained localhost compatibility relay.

START OR REPAIR
Double-click this Desktop shortcut:
  Start or Repair Codex Copilot Bridge

RESTORE NORMAL CODEX AND STOP THE BRIDGE
Double-click this Desktop shortcut:
  Restore Normal Codex (Disable Copilot Bridge)

DASHBOARD
http://127.0.0.1:4144/dashboard

The watchdog automatically restarts the bridge and visible gateway terminal.
The relay keeps Codex's normal Responses streaming, tools, parallel agents, and
child-agent continuation while model inference is routed through Copilot.
Quiet model work is kept alive with parsed Responses events; abandoned clients
are cleaned up instead of remaining as orphaned dashboard exchanges.
Outer tool calls may remain open for up to 13 hours by default.
Use the Restore shortcut before renaming, moving, or deleting this folder.
After Start or Restore, reopen the Codex task once so it reloads config.toml.
